# Account linking

1. Sign in at [FiveM Media](https://media.dnnsitelaunch.com/).
2. Open Creator Dashboard → Link FiveM Account.
3. Generate a one-time link code.
4. Join a server with the verified FiveM Media resource.
5. Enter the code in chat:

```text
/fmlink FM-LINK-XXXXXXXX
```

6. Wait for the success message.

Use the exact code shown in your dashboard. Treat it like a temporary credential and do not share it. If it expires, generate another code.
